## Runtime boundary

Keep Cesium, navigation/tracking, application lifecycle and source interfaces. Adapt existing control owners to a shared host incrementally. The current standalone factory has a page singleton and is not a removable/multiple-viewer shell. Preserve public share-link compatibility, attribution and explicit source unavailability.

The fork now wires a local NeighborOS shell through a paired Node HTTP transport and private Rust stdio worker to actual Quanta core/world storage. See [the run guide](NEIGHBOROS.md) and [executed build evidence](../../research/unified-world/build-001/REPORT.md). The browser cannot choose its principal. This does not add authentication to inherited provider/MCP routes or establish hosted multi-user security. World fact reads still scan; valid-time history and independent source-version verification remain unsupported.
